# 库存保持

设置材料目标后，助手先读取当前持有数量，再按列表顺序调用原生副本；每完成一场重新读取。全部达标或自然波片不足就结束，不购买、不使用备用体力，不修改原有日常刷取计划。

## 使用

1. 先打开游戏并进入大世界。
2. 打开侧栏「库存保持」，点「设置材料目标」。新增材料、填写目标，拖动列表决定优先顺序后保存。
3. 「只查库存」只读取；「补齐库存」允许消耗自然波片。任务栏也提供这两个独立任务。

列表显示「材料名称：上次持有数量/目标数量」。历史数量仅用于展示，不能作为本次刷取依据。空目标列表不刷取。

## 范围与边界

- 提供 49 项可补刷目标：凝素领域材料、角色/武器经验材料和贝币。不含普通首领突破材料；战歌重奏属于独立任务，不在这里补刷。
- 同系列材料按换算规则判断缺口，不能向下转换的品质不反向计算；不自动执行合成。
- 通过当前助手截图和 OCR 读取材料名称及精确持有数，连续两帧确认；缩略数字、名称不符、版本不符或窗口失去执行权时拒绝补刷。
- 刷取复用 SimulationTask / ForgeryTask，只执行单倍单场；不修改原任务的持久配置。可能已扣波片但无法核实结算时留下 pending 记录，停止自动重试。
- 识别配方和记录位于助手根目录 config/inventory_extension，随包提供相对路径资源，不需要另一套助手或开发者电脑上的脚本。
- 扩展材料识别为可试用，不代表每种材料都已单独实机验证。游戏更新后版本不一致时会明确失败，须重新核对识别配方，不能直接放行旧数据。

## 验证

测试覆盖库存排序/换算、真实原生刷取接口的模拟调用、配置保存失败、重复结算保护、双帧读取和离屏设置保存。没有在本 PR 发布阶段启动游戏或消耗波片，离线通过不等于全部材料实机验收。
