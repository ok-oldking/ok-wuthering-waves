# macOS 内部版安装与使用

当前 contributor 分支的 packaged MVP 要求 **Apple Silicon Mac、macOS 15.0 或更新系统**，配合官方《鸣潮》Mac 客户端，仅在游戏处于前台时运行。Intel Mac、macOS 13/14、后台或最小化自动化不受当前包支持。系统最低版本不代表所有任务已经验收通过。

当前仍为内部测试版，尚未达到最终 MVP 或公开发行门槛；没有公开发行下载或签名/公证通过承诺。产品版本边界见 [ADR 0003](development/decisions/0003-macos-packaged-minimum-version.md)，各任务实际状态见 [能力与任务矩阵](development/macos-capability-matrix.md)。`ok-script` 的 macOS 13+ API 设计不能用来判断当前安装包兼容性。

## 安装与权限

1. 检查“关于本机”中的芯片与系统版本，确认满足 Apple Silicon、macOS 15+。使用明确提供给本次内部测试、来源和版本可核对的 `.app`。
2. 正常退出已有 OK-WW，保留旧包供回滚，再将本次包安装至 `/Applications/OK-WW.app`。从该位置启动；不要把 DMG 内运行当作标准安装方式。
3. 按应用提示在“系统设置 → 隐私与安全性”中为该应用授予屏幕录制和辅助功能权限。系统名称可能显示“屏幕与系统音频录制”。Terminal/Python 的授权不能代替 `.app` 授权。
4. 若系统阻止当前内部包启动，停止并核对该产物与提供者的安装说明；不要关闭 Gatekeeper、移除隔离属性或修改 TCC 数据库来绕过检查。
5. 在权限/窗口面板刷新状态，选择官方鸣潮主窗口并点击“绑定并连接截图”。先确认截图正确、没有标题栏/边框/其他桌面内容；连接成功不代表已经开始任务。

内部包重建后的签名身份可能变化，历史上已观察到需要重新授权；稳定 bundle ID 不保证跨重建保留权限。以当前安装产物显示的状态为准。

## 开始、停止与限制

选择当前允许使用的任务，按需设置准备时间，再发起开始/恢复并切回游戏。应用等待游戏实际成为前台；绑定、权限、新鲜帧、坐标与任务能力检查全部通过后才允许输入。切走、任务停止、目标丢失、权限撤销或截图失败时会释放合成按键/鼠标并暂停或停止。恢复需要用户显式操作，不能依赖后台自动续跑。

`experimental` 表示待验收，不等于稳定支持；`unsupported` 不可执行，未声明任务也拒绝执行。自由相对镜头、完整跑图和 Windows 功能对等尚无支持承诺。16:9 与原生 16:10 的真机证据分别记录，旧包的成功不能直接用于新版本。

## 更新、回滚与数据

更新前正常停止任务并退出应用，保留原产物和对应版本记录。用户数据位于用户 Library/Application Support/OK-WW Foreground 下，配置、日志、截图与自定义任务不会因本文的系统基线决定迁移；不要手工放入 `.app`。回滚时退出新包后恢复精确旧包，保留用户数据，并重新检查权限与窗口绑定。

macOS 13/14 用户不能通过修改 plist、Mach-O 或启动参数获得当前包兼容性。恢复旧系统支持需要一套实际兼容且经过目标系统验证的依赖与新包；目前未提供该承诺。升级操作系统由用户自行决定。

内部包、source 测试与真实任务的详细证据见 [内部包验收记录](development/macos-internal-acceptance.md)。Developer ID、公证、staple 和 clean-user Gatekeeper 仍属公开发行门槛，本文不表示本轮完成了这些验证。
