# 识别模板源文件 / Recognition Template Sources

本目录的源图片和 `coco_annotations.json` 直接保存在 ok-ww 仓库中。

The source images and `coco_annotations.json` in this directory are tracked directly in the ok-ww repository.

1. 在 ok-ww 的「模板」标签页中添加图片并完成标注。
2. 点击「保存」，保存标注并生成 `assets/` 中的识别素材。
3. 检查生成的修改，将相关源图片、标注和识别素材一起提交。

1. Add the images and markup in ok-ww's Template tab.
2. Click Save to save the annotations and generate recognition assets in `assets/`.
3. Review the generated changes and commit the relevant source images, annotations, and recognition assets together.
